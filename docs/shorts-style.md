# Основной стиль для вертикальных роликов

Основной формат — 9:16, 1080×1920. Стиль `shorts` выбран по умолчанию: крупный жирный жёлтый текст с белой обводкой, обычно два-три слова в группе. Каждое слово немного увеличивается во время произнесения и возвращается к обычному размеру к концу своего интервала. Остальные слова видны в обычном размере.

## Настройки

Все параметры находятся в `subtitle_forge/styles/shorts.py`:

- `CONFIG`: шрифт DejaVu Sans, размер 90 в координатах ASS, жёлтый `&H0000E8FF`, белая обводка 2,5, тень 2, отступ снизу 470.
- `MAX_WORDS = 3`: максимум три слова в группе. Четыре слова распределяются как 2+2, если это позволяет разбиение по длине.
- `MAX_CHARS = 20`: ориентир для длины строки; длинные слова могут переноситься на следующую строку.
- `ACTIVE_SCALE = 1.12`: активное слово увеличивается приблизительно на 12%.
- `MAX_ANIMATION_MS = 70`: нарастание и спад занимают до 70 мс каждый; у коротких слов время уменьшается.
- `PAUSE_SPLIT_SECONDS = 0.45`: пауза больше 450 мс начинает новую группу. Конец предложения также разделяет группы.

Паузы внутри группы не скрывают текст. Увеличение каждого слова привязано к его собственным меткам Whisper, включая паузы между словами. Одиночные слова возможны у коротких реплик, концов предложений или отдельных слов после длинной паузы. SRT без меток слов для этого стиля не подходит.

## Запуск

```sh
python3 -m subtitle_forge generate transcript.json \
  -o shorts.ass --burn input.mp4 --video-output shorts.mp4
```

Результат имеет разрешение 1080×1920. По умолчанию `--video-fit pad` сохраняет исходную сцену целиком и добавляет поля. Чтобы заполнить вертикальный кадр с обрезкой краёв по центру:

```sh
python3 -m subtitle_forge generate transcript.json \
  -o shorts.ass --burn input.mp4 --video-output shorts.mp4 \
  --video-fit crop
```

`crop` не отслеживает лица. Разрешение можно изменить аргументами `--width` и `--height`; для прожига оба размера должны быть чётными. Для горизонтального экспорта явно укажите, например, `--width 1920 --height 1080` и настройте размер/отступ текста под кадр. Остальные пять стилей сохранены и выбираются через `--style`.

## Визуальные референсы

Просмотрены кадры двух реальных Shorts:

- [Фрагмент «Форрест Гамп» на Top.Movie.Moment](https://www.youtube.com/shorts/Pur2mt1JTZo): вертикальная нарезка, короткие крупные жирные подписи; в просмотренном кадре белый текст с толстой чёрной обводкой.
- [Short с жёлтыми субтитрами](https://www.youtube.com/shorts/bAZRCoWdf8Q): жёлтое слово с тёмной обводкой, видимое отдельно от остальной сцены.

Новый стиль соединяет короткие группы и акцент на активном слове с заданными пользователем жёлтой заливкой и белой обводкой. Он не является точной копией этих роликов. Поиск не подтверждает, что каждый референс является вирусным; оформление проверено по самим видео.

## Проверка 30 октября 2026

Созданы две новые версии ранее скачанного 19-секундного ролика «Me at the zoo» с реальным транскриптом Whisper:

```sh
python3 -m subtitle_forge generate demo-youtube/transcript.json \
  -o demo-youtube/shorts.ass --burn demo-youtube/source.mp4 \
  --video-output demo-youtube/shorts-vertical.mp4 --video-fit crop

python3 -m subtitle_forge generate demo-youtube/transcript.json \
  -o demo-youtube/shorts-pad.ass --burn demo-youtube/source.mp4 \
  --video-output demo-youtube/shorts-vertical-pad.mp4
```

У версии с обрезкой подтверждены кадр 1080×1920, длительность 19,021 секунды, отсутствие ошибок при полном декодировании и совпадение SHA-256 исходного/выходного аудиопотока. Просмотрен кадр с тремя крупными словами, жёлтой заливкой и белой обводкой.

На отдельном синтетическом ролике с фразой `ECHO ECHO ECHO` просмотрены кадры первого и второго активного слова: растёт только текущее слово. Это проверка анимации, а не точности распознавания речи.

В автоматические тесты добавлены группировка, изоляция анимации, вертикальные настройки, CLI по умолчанию и прожиг через FFmpeg. Интеграционная проверка создаёт горизонтальный ролик со звуком и проверяет обе версии `pad`/`crop`: выходные размеры, наличие аудио и успешное декодирование. При отсутствии FFmpeg/ffprobe интеграционный тест пропускается.

Медиа и скачанные референсы лежат локально в игнорируемом каталоге `demo-youtube/`. Исходный отчёт прежних пяти стилей сохранён в [youtube-smoke-test.md](youtube-smoke-test.md).
