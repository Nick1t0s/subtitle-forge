# Стиль для вертикальных роликов

Основной формат — вертикальный 9:16, 1080×1920. Стиль `shorts` выбран по умолчанию; остальные встроенные стили сохранены и выбираются через `--style`.

## Внешний вид и тайминг

Стандартная конфигурация в `subtitle_forge/styles/shorts.py`:

- жирный DejaVu Sans, размер 90 в координатах ASS;
- жёлтая заливка `&H0000E8FF`, белая обводка шириной 2.5, тень 2;
- активное слово отображается в 1.35 раза крупнее (на 35%), остальные — в обычном размере;
- размер активного слова меняется мгновенно по границе временной метки, без анимации увеличения/уменьшения;
- каждое слово размещено по фиксированному центру. Для слотов заранее резервируется ширина слова в увеличенном состоянии, поэтому при смене активного слова соседние слова не сдвигаются;
- текущее слово остаётся увеличенным до начала следующего слова, в том числе во время паузы. Последняя группа остаётся на экране до конца сегмента. До начала первого слова группы титров нет.

Слова кодируются отдельными ASS-событиями с абсолютным позиционированием `\\pos` и выравниванием по центру `\\an5`. Ширина слов рассчитывается по установленному жирному шрифту, чтобы зарезервировать место для максимального размера и ровно центрировать всю группу.

## Группировка

- В группе не больше трёх слов.
- Четыре соседних слова обычно распределяются как 2+2, если это позволяет ограничение ширины.
- Короткие реплики, знаки конца предложения и длинные паузы могут давать однословные группы.
- Конец предложения или пауза дольше 0.45 секунды начинает новую группу.
- Длина строки обычно ограничивается 20 символами; очень длинные слова могут переноситься.

SRT не подходит для `shorts`: у SRT cue нет меток отдельных слов. Используйте JSON с `words` и корректными временными границами. Слова в наборе транскрипта должны быть упорядочены и не пересекаться; для стиля `shorts` последовательность меток также должна оставаться упорядоченной между группами.

## Шрифт и раскладка

Для расчёта фиксированных центров стиль запускает `fc-match` из Fontconfig и читает таблицы метрик установленного жирного TTF/OTF. Это не Python-зависимость, но для `shorts` нужны установленный `fc-match` и подходящий шрифт. Коллекции TTC не поддерживаются. Для другого семейства используйте `--font`; чтобы символы не заменялись на отсутствующие глифы, выбранный шрифт должен содержать нужный язык. Если группа шире доступного места, размер шрифта для неё уменьшается пропорционально. Центры рассчитаны с учётом максимального масштаба 1.35× и не пересчитываются при смене слова.

При передаче пользовательского стиля CLI включает фактические размеры кадра в `StyleConfig.canvas_width` и `StyleConfig.canvas_height` наряду с `width` и `height` документа ASS. Поэтому `shorts` раскладывает слова относительно целевого кадра.

## Запуск и режим кадрирования

```sh
python3 -m subtitle_forge generate transcript.json \
  -o shorts.ass --burn input.mp4 --video-output shorts.mp4
```

По умолчанию выход — 1080×1920, а `--video-fit pad` сохраняет исходную сцену целиком и добавляет поля при несовпадении пропорций. Чтобы заполнить вертикальный кадр обрезкой краёв по центру:

```sh
python3 -m subtitle_forge generate transcript.json \
  -o shorts.ass --burn input.mp4 --video-output shorts.mp4 \
  --video-fit crop
```

`crop` не отслеживает лица. Целевые размеры задаются `--width` и `--height`; при прожиге H.264/yuv420p оба должны быть чётными. Для генерации ASS без видео можно задать нечётные размеры.

## Визуальные референсы

Просмотрены кадры двух реальных Shorts:

- [Фрагмент «Форрест Гамп» на Top.Movie.Moment](https://www.youtube.com/shorts/Pur2mt1JTZo): вертикальная нарезка, короткие крупные жирные подписи; в просмотренном кадре белый текст с толстой чёрной обводкой.
- [Short с жёлтыми субтитрами](https://www.youtube.com/shorts/bAZRCoWdf8Q): жёлтое слово с тёмной обводкой, видимое отдельно от остальной сцены.

Стиль сочетает короткие группы, крупный текст и акцент на текущем слове с заданным жёлтым цветом и белой обводкой. Он не является точной копией этих видео. Поиск не подтверждает, что каждый референс является вирусным; оформление проверено по самим роликам.

## Проверка реализации

Результаты фактического прогона и проверки видео фиксируются в [youtube-smoke-test.md](youtube-smoke-test.md). Дополнительный русскоязычный результат находится локально в `demo-youtube/russian/shorts-ru-fixed.mp4`.

На контрольном ролике `ECHO ECHO ECHO` просмотрены кадры на 0,4 и 1,1 секунды: центры трёх слов сохраняются, меняется размер только активного слова. На кадре 0,8 секунды (пауза до второго слова) первое слово остаётся увеличенным. Просмотрен также кадр русского ролика на 17,3 секунды. Новый русский MP4 полностью декодирован FFmpeg без ошибок.

Масштаб активного слова задан тегами ASS как 135%; тайминг округляется форматом ASS до сотых секунды. До первого слова титров нет, пока группа видна — увеличено ровно одно событие слова. Токен с несколькими словами учитывается по фактическому количеству слов при разбиении, чтобы суммарно не показывать больше трёх.
