# Однословный стиль Impact

Стили `impact-bottom` и `impact-center` добавляют отдельный вариант титров для вертикальных роликов. Существующий стиль `shorts` остаётся без изменений.

## Внешний вид и тайминг

В качестве визуального ориентира использован [YouTube Shorts](https://www.youtube.com/shorts/4J9Gg4PXOHY). В нём показано одно слово за раз: очень жирные узкие белые буквы с толстой чёрной обводкой. Регистр исходного слова сохраняется, слова переключаются резко, без анимации. Для этого вида подобран Oswald Bold; это визуально близкая замена, а не утверждение, что в исходном видео использован именно этот шрифт.

Оба стиля по умолчанию задают Oswald, размер 128, белую заливку, чёрную обводку шириной 8 и тень 2 в координатах ASS. Каждое слово получает собственное событие и абсолютную центральную позицию. Текст берётся из словесных меток, а не из текста сегмента.

- `impact-bottom` размещает слово по центру по горизонтали, у нижнего края: выравнивание ASS 2 и нижнее поле 260.
- `impact-center` размещает слово в геометрическом центре кадра: выравнивание ASS 5 и вертикальная координата `height / 2`.
- На короткой паузе до следующего слова (не более 0,45 секунды) текущее слово остаётся на экране до начала следующего. При более длинной паузе титр заканчивается вместе со словом.
- Слишком широкое слово автоматически уменьшается, чтобы поместиться в ширину кадра с боковыми полями.

Для точного переключения по словам нужны отдельные временные метки каждого слова. Обычный SRT содержит только интервалы реплик, поэтому с этими стилями не используется. JSON транскрипт должен включать массив `words`; метки должны быть упорядочены и не пересекаться.

## Запуск

Сгенерировать ASS-файл можно так:

```sh
python3 -m subtitle_forge generate transcript.json \
  --style impact-bottom -o impact-bottom.ass

python3 -m subtitle_forge generate transcript.json \
  --style impact-center -o impact-center.ass
```

Чтобы сразу прожечь титры в видео, передайте `--burn` и `--video-output`:

```sh
python3 -m subtitle_forge generate transcript.json \
  --style impact-bottom -o impact-bottom.ass \
  --burn input.mp4 --video-output impact-bottom.mp4
```

Обе сборки примера на русском находятся в `demo-youtube/russian/`: `impact-bottom.mp4` и `impact-center.mp4`.

## Шрифт

В проект включён Oswald Bold с лицензией OFL; при прожиге через Subtitle Forge он передаётся FFmpeg как доступный шрифт. При использовании отдельного ASS-файла в другом плеере установите Oswald Bold в системе либо настройте папку шрифтов FFmpeg для этого плеера, иначе он может подставить другой шрифт. Координаты `\pos` вычисляются по размерам целевого кадра, поэтому задавайте те же `--width` и `--height` при генерации, что и целевые размеры видео.

Источник файла шрифта и лицензии: [официальный репозиторий Oswald](https://github.com/googlefonts/OswaldFont). Имя стилей описывает визуальное оформление; файл шрифта Microsoft Impact в проект не включён.

## Проверка

Оба варианта прожжены в ранее подготовленный русский ролик 1080×1920 и полностью декодированы FFmpeg без ошибок. Просмотрены кадры на 18,5 секунды: белый текст с чёрной обводкой расположен внизу и в центре соответственно.

Все 34 теста прошли, включая переключение слов, короткие/длинные паузы, разные положения и размеры кадра. Собран wheel, установлен в чистое временное окружение; проверены наличие файла шрифта и лицензии в пакете, измерение кириллицы и создание ASS через установленную CLI-команду.
