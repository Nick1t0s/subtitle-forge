# Проверка на видео с YouTube

Проведена 30 октября 2026 года на локальной машине. Проверен полный путь: скачивание → распознавание → ASS → видео с субтитрами. Сгенерированы все пять стилей.

## Исходник и окружение

- Видео: [Me at the zoo](https://www.youtube.com/watch?v=jNQXAC9IVRw).
- Длительность: 19,021 секунды; кадр: 320×240; исходные кодеки: AV1 + Opus.
- Загрузка: установленный yt-dlp 2026.08.19.
- Распознавание: существующее `~/whisper-venv/bin/python`, faster-whisper, локальная модель `large-v3-turbo`, CUDA, float16, `word_timestamps=True`, `vad_filter=True`, язык `en`.
- Результат распознавания: 5 сегментов, 36 слов с временными метками.

## Команды воспроизведения

Запускать из корня проекта. Для повторного запуска поверх существующих результатов добавьте `--overwrite` к командам Subtitle Forge.

```sh
mkdir -p demo-youtube
yt-dlp --no-playlist --max-filesize 80M \
  -f 'bv*[height<=480]+ba/b[height<=480]/best' \
  --merge-output-format mp4 --write-info-json \
  -o 'demo-youtube/source.%(ext)s' \
  'https://www.youtube.com/watch?v=jNQXAC9IVRw'

python3 -m subtitle_forge transcribe demo-youtube/source.mp4 \
  -o demo-youtube/transcript.json --language en

for style in classic word karaoke typewriter pop; do
  python3 -m subtitle_forge generate demo-youtube/transcript.json \
    -o "demo-youtube/$style.ass" --style "$style" \
    --width 320 --height 240 --font-size 17 --margin-v 16 \
    --burn demo-youtube/source.mp4 \
    --video-output "demo-youtube/$style.mp4"
done
```

Загрузчик предупредил об отсутствии JavaScript runtime, но выбранный ролик успешно скачался и объединился. Для других роликов доступность форматов может отличаться.

## Что проверено

- Все 15 unit/CLI-тестов прошли: `python3 -m unittest discover -s tests -v`.
- Реальный вывод Whisper успешно прошёл проверку модели данных и принят всеми стилями без ручной правки.
- Каждый MP4 полностью декодирован командой `ffmpeg -v error -i VIDEO -f null -` без ошибок.
- Через ffprobe проверены размеры, длительность и кодеки всех выходов.
- Визуально просмотрен кадр на отметке 2,5 секунды каждого из пяти выходов: текст виден и помещается в кадр; у karaoke видно выделение активного слова.
- Контрольные суммы исходного и всех выходных аудиопотоков совпадают. Проверка: `ffmpeg -v error -i VIDEO -map 0:a:0 -c copy -f streamhash -hash sha256 -`. Во всех случаях SHA-256: `4aa4ce841d4ddd9d33b680a93db320e4f62c240b53fd90673440277f17083e46`.

## Ограничения проверки

Успешный рендер не гарантирует точного распознавания речи. В автоматическом транскрипте встречается, например, слово `fronts` в реплике об elephant trunks. Для публикации текст следует вычитать; исходные ошибки Whisper оставлены в этом тесте без исправления. Временные метки также являются оценкой модели, а ASS дополнительно округляет их до сотых секунды.

Просмотр отдельных кадров проверяет оформление, но не заменяет полный просмотр ролика со звуком и ручную оценку синхронизации. Сохранность аудио проверена по потоку. Совместимость MP4 с Opus зависит от проигрывателя; FFmpeg успешно декодировал полученные файлы.
